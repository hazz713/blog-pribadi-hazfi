Eloquent

Halaman ini berisi materi lanjutan tentang Eloquent pada Laravel, mulai dari CRUD pada tabel t_kelas, pembuatan data guru dengan ORM, sampai penjelasan perbedaan antara DB Facade dan Eloquent.

Eloquent Studi Kasus 1-3

Materi Eloquent

Pada materi ini, saya mulai mempelajari penggunaan Eloquent sebagai ORM di Laravel. Dengan Eloquent, pengolahan data terasa lebih sederhana karena saya bisa memakai model untuk create, edit, update, dan delete tanpa harus menulis query manual terlalu banyak.

Studi Kasus 1

Lakukan hal yang sama untuk tabel t_kelas (Create, Edit dan Delete).

Pada studi kasus pertama, saya diminta melakukan operasi create, edit, dan delete pada tabel t_kelas menggunakan Eloquent.

Source code KelasController dengan Eloquent

<?php

namespace App\Http\Controllers;

use App\Models\Kelas;
use Illuminate\Http\Request;

class KelasController extends Controller
{
    public function index()
    {
        $data = Kelas::orderBy('id')->get();
        return view('kelas.index', compact('data'));
    }

    public function create()
    {
        return view('kelas.create');
    }

    public function store(Request $request)
    {
        $input = $request->validate([
            'nama_kelas' => 'required|string|max:100',
            'jurusan' => 'required|string|max:55',
            'lokasi_ruangan' => 'required|string|max:50',
            'nama_wali_kelas' => 'required|string|max:50',
        ]);

        $status = Kelas::create($input);

        if ($status) {
            return redirect()->route('kelas.index')->with('success', 'Data berhasil disimpan!');
        }

        return redirect()->route('kelas.index')->with('error', 'Data gagal disimpan!');
    }

    public function edit($id)
    {
        $kelas = Kelas::findOrFail($id);
        return view('kelas.create', compact('kelas'));
    }

    public function update(Request $request, $id)
    {
        $input = $request->validate([
            'nama_kelas' => 'required|string|max:100',
            'jurusan' => 'required|string|max:55',
            'lokasi_ruangan' => 'required|string|max:50',
            'nama_wali_kelas' => 'required|string|max:50',
        ]);

        $kelas = Kelas::findOrFail($id);
        $status = $kelas->update($input);

        if ($status) {
            return redirect()->route('kelas.index')->with('success', 'Data berhasil diupdate!');
        }

        return redirect()->route('kelas.index')->with('error', 'Data gagal diupdate!');
    }

    public function destroy($id)
    {
        $kelas = Kelas::findOrFail($id);
        $status = $kelas->delete();

        if ($status) {
            return redirect()->route('kelas.index')->with('success', 'Data berhasil dihapus!');
        }

        return redirect()->route('kelas.index')->with('error', 'Data gagal dihapus!');
    }
}

Studi Kasus 2

Buatlah tabel baru untuk menyimpan data guru dan view untuk CRUD-nya. Cobalah gunakan metode ORM untuk insert dan update data guru tersebut.

Pada studi kasus kedua, saya diminta membuat tabel baru untuk data guru, lalu menggunakan metode ORM pada Eloquent untuk melakukan insert, edit, update, dan delete.

Source code GuruController dengan ORM

<?php

namespace App\Http\Controllers;

use App\Models\Guru;
use Illuminate\Http\Request;

class GuruController extends Controller
{
    public function index()
    {
        $guru = Guru::orderBy('nama_guru')->get();
        return view('guru.form', compact('guru'));
    }

    public function store(Request $request)
    {
        $input = $request->validate([
            'nip' => 'required|string|max:30',
            'nama_guru' => 'required|string|max:100',
            'jenis_kelamin' => 'required|in:L,P',
            'alamat' => 'required|string|max:255',
        ]);

        $status = Guru::create($input);

        if ($status) {
            return redirect()->route('guru.index')->with('success', 'Data guru berhasil ditambahkan');
        }

        return redirect()->route('guru.index')->with('error', 'Data guru gagal ditambahkan');
    }

    public function edit($id)
    {
        $edit = Guru::findOrFail($id);
        $guru = Guru::orderBy('nama_guru')->get();
        return view('guru.form', compact('edit', 'guru'));
    }

    public function update(Request $request, $id)
    {
        $input = $request->validate([
            'nip' => 'required|string|max:30',
            'nama_guru' => 'required|string|max:100',
            'jenis_kelamin' => 'required|in:L,P',
            'alamat' => 'required|string|max:255',
        ]);

        $guru = Guru::findOrFail($id);
        $guru->nip = $input['nip'];
        $guru->nama_guru = $input['nama_guru'];
        $guru->jenis_kelamin = $input['jenis_kelamin'];
        $guru->alamat = $input['alamat'];
        $status = $guru->save();

        if ($status) {
            return redirect()->route('guru.index')->with('success', 'Data guru berhasil diupdate');
        }

        return redirect()->route('guru.index')->with('error', 'Data guru gagal diupdate');
    }

    public function destroy($id)
    {
        $guru = Guru::findOrFail($id);
        $status = $guru->delete();

        if ($status) {
            return redirect()->route('guru.index')->with('success', 'Data guru berhasil dihapus');
        }

        return redirect()->route('guru.index')->with('error', 'Data guru gagal dihapus');
    }
}

Studi Kasus 3

Bisakah anda menjelaskan perbedaan yang signifikan antara penggunaan DB Facades dan Eloquent?

Menurut saya, perbedaan antara DB Facade dan Eloquent ada pada cara kita menulis kode dan tingkat kemudahannya.

Kalau DB Facade, kita menulis query lebih manual dan lebih dekat ke gaya query database. Karena itu kita harus menyebut tabelnya langsung dan mengatur sendiri data yang dipakai. Cara ini lebih fleksibel, tetapi kadang terasa lebih panjang dan lebih ribet.

Sedangkan Eloquent lebih sederhana karena memakai model. Kita tidak perlu menulis query secara detail setiap saat, cukup memanggil model yang sesuai. Menurut saya, cara ini membuat kode lebih rapi, lebih mudah dibaca, dan lebih cepat dibuat.
