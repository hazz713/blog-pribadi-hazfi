# Blog Pribadi Hazfi


## Isi

- `index.html` untuk halaman utama blog
- `styles.css` untuk desain blog
- `script.js` untuk animasi ringan

## Cara buka

Buka file `blog-pribadi-hazfi/index.html` di browser.

## Catatan

Versi ini adalah tampilan awal blog pribadi yang netral. Konten artikel project Laravel bisa ditambahkan pada tahap berikutnya.

## Siap Upload ke GitHub Pages

Folder `blog-pribadi-hazfi` ini sudah menggunakan file yang cocok untuk website statis:

- `index.html` sebagai halaman utama
- `framework.html` untuk materi framework Laravel
- `migration.html` untuk materi database migration
- `controller.html` untuk materi controller dan Facade DB
- `create-data.html` untuk materi create data with Facade DB
- `edit-delete.html` untuk materi edit dan delete data
- `styles.css` sebagai tampilan
- `script.js` sebagai animasi
- `assets/` untuk foto dan screenshot

Supaya bisa dijadikan link website, upload semua isi folder ini ke repository GitHub baru.

## Langkah Publish Link

1. Buka GitHub lalu login ke akun kamu.
2. Klik `New repository`.
3. Isi nama repository, misalnya `blog-pribadi-hazfi`.
4. Klik `Create repository`.
5. Buka repository yang baru dibuat.
6. Klik `Add file` lalu pilih `Upload files`.
7. Masukkan semua isi folder `blog-pribadi-hazfi`:
   - `index.html`
   - `styles.css`
   - `script.js`
   - folder `assets`
8. Klik `Commit changes`.
9. Masuk ke `Settings`.
10. Klik menu `Pages`.
11. Pada bagian `Build and deployment`, pilih `Deploy from a branch`.
12. Pada branch pilih `main`.
13. Pada folder pilih `/root`.
14. Klik `Save`.
15. Tunggu beberapa saat sampai GitHub selesai publish.
16. Link website akan muncul di halaman `Pages`.

## Bentuk Link

Biasanya link website kamu akan seperti ini:

`https://usernamekamu.github.io/blog-pribadi-hazfi/`
