Database Migration

Halaman ini berisi materi database migration pada Laravel, mulai dari pembuatan tabel baru sampai perubahan struktur tabel menggunakan migration.

Database Migration Studi Kasus Baru

Database Migration pada Laravel

Pada bagian ini, saya mempelajari bagaimana Laravel menggunakan migration untuk membuat dan mengubah struktur tabel database secara rapi. Dengan migration, proses pembuatan tabel menjadi lebih terstruktur karena semua perubahan bisa ditulis dalam bentuk kode.

Pada materi ini saya mengerjakan studi kasus pembuatan tabel baru, lalu melanjutkan dengan beberapa perubahan struktur tabel menggunakan migration data. Agar pembahasan lebih jelas, saya menuliskan source code contoh langsung di halaman ini tanpa menggunakan screenshot.

Studi Kasus 1

Buatlah migrasi baru untuk membuat tabel t_percobaan. Cobalah buat minimal 15 field yang berbeda pada tabel tersebut.

Pada studi kasus pertama, saya diminta membuat tabel baru dengan minimal 15 field. Pada kode yang saya kerjakan, tabel tersebut saya tulis dengan nama t_siswa. Dari latihan ini saya belajar bahwa migration dapat dipakai untuk membuat struktur tabel secara lengkap mulai dari field identitas sampai data tambahan lainnya.

Contoh migration tabel t_siswa

use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration
{
    public function up(): void
    {
        Schema::create('t_siswa', function (Blueprint $table) {
            $table->id();
            $table->integer('nis');
            $table->string('nama_lengkap', 100);
            $table->date('tanggal_lahir');
            $table->string('jenis_kelamin', 10);
            $table->string('alamat', 100);
            $table->string('kelas', 10);
            $table->string('no_telpon', 15);
            $table->string('jurusan', 50);
            $table->string('email', 50);
            $table->string('agama', 50);
            $table->string('hobi', 100);
            $table->string('sekolah', 100);
            $table->string('tempat_lahir', 100);
            $table->string('nama_ibu', 100);
            $table->string('nama_ayah', 100);
            $table->timestamps();
        });
    }

    public function down(): void
    {
        Schema::dropIfExists('t_siswa');
    }
};

Dari contoh di atas, saya memahami bahwa migration bukan hanya membuat satu atau dua field, tetapi bisa langsung membentuk keseluruhan tabel dalam satu file yang rapi.

Studi Kasus 2

Membuat Migrasi Data pada Tabel t_kelas

Pada studi kasus kedua, saya melanjutkan pembelajaran dengan membuat tabel t_kelas, lalu melakukan beberapa perubahan struktur tabel secara bertahap. Dari tugas ini saya belajar bahwa migration juga bisa dipakai untuk menambah, mengubah, dan mengganti nama field pada tabel yang sudah ada.

  • Membuat tabel t_kelas dengan field nama_sekolah dan jurusan.
  • Menambahkan field lokasi_ruangan.
  • Mengubah panjang field jurusan.
  • Menambahkan field nama_wakel.
  • Mengubah nama field nama_wakel menjadi nama_wali_kelas.

Langkah 1

Buatlah tabel t_kelas dengan field nama_kelas, jurusan

Migration awal tabel t_kelas

use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration
{
    public function up(): void
    {
        Schema::create('t_kelas', function (Blueprint $table) {
            $table->id();
            $table->timestamps();
            $table->string('nama_sekolah', 100);
            $table->string('jurusan', 100);
        });
    }

    public function down(): void
    {
        Schema::dropIfExists('t_kelas');
    }
};

Pada langkah awal ini, saya mulai dari membuat tabel dasar terlebih dahulu sebelum melakukan perubahan pada field-field berikutnya.

Langkah 2

Buatlah perubahan tabel t_kelas dengan menambahkan field lokasi_ruangan

Migration menambah lokasi_ruangan

use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration
{
    public function up(): void
    {
        Schema::table('t_kelas', function (Blueprint $table) {
            $table->string('lokasi_ruangan', 50)->after('jurusan');
        });
    }

    public function down(): void
    {
        Schema::table('t_kelas', function (Blueprint $table) {
            $table->dropColumn('lokasi_ruangan');
        });
    }
};

Dari langkah ini saya belajar cara menambahkan kolom baru ke tabel yang sudah dibuat sebelumnya.

Langkah 3

Buatlah perubahan tabel t_kelas, jurusan dengan mengganti panjangnya

Migration mengubah panjang jurusan

use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration
{
    public function up(): void
    {
        Schema::table('t_kelas', function (Blueprint $table) {
            $table->string('jurusan', 55)->change();
        });
    }

    public function down(): void
    {
        Schema::table('t_kelas', function (Blueprint $table) {
            $table->string('jurusan')->change();
        });
    }
};

Pada bagian ini saya memahami bahwa field yang sudah ada pun tetap bisa diubah kembali sesuai kebutuhan.

Langkah 4

Buatlah perubahan tabel t_kelas dengan menambahkan field nama_wakel

Migration menambah nama_wakel

use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration
{
    public function up(): void
    {
        Schema::table('t_kelas', function (Blueprint $table) {
            $table->string('nama_wakel', 50)->after('lokasi_ruangan');
        });
    }

    public function down(): void
    {
        Schema::table('t_kelas', function (Blueprint $table) {
            $table->dropColumn('nama_wakel');
        });
    }
};

Migration ini memperlihatkan bahwa penambahan field baru bisa dilakukan berulang sesuai perkembangan data.

Langkah 5

Buatlah perubahan tabel t_kelas dengan mengubah nama field nama_wakel menjadi nama_wali_kelas

Migration rename field

use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration
{
    public function up(): void
    {
        Schema::table('t_kelas', function (Blueprint $table) {
            $table->renameColumn('nama_wakel', 'nama_wali_kelas');
        });
    }

    public function down(): void
    {
        Schema::table('t_kelas', function (Blueprint $table) {
            $table->renameColumn('nama_wali_kelas', 'nama_wakel');
        });
    }
};

Dari bagian ini saya belajar bahwa Laravel juga menyediakan cara untuk mengganti nama field tanpa harus membuat tabel baru dari awal.

Kesimpulan

Pemahaman yang Saya Dapatkan

Setelah mengerjakan materi database migration ini, saya menjadi lebih paham bahwa migration sangat berguna untuk membuat dan mengelola struktur database secara bertahap. Saya juga belajar bahwa perubahan tabel bisa dilakukan dengan lebih rapi karena semua langkah tersimpan dalam kode.

Menurut saya, penggunaan migration sangat membantu dalam pengembangan project Laravel karena struktur database menjadi lebih mudah dipelajari, diperbaiki, dan dikembangkan kembali.
